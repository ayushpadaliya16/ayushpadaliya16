🥇 **Agri-Safe AI (1st Place Winner - AIDEA FORGE Hackathon)**
*   **What it is:** A smart software system built to help farmers work safer and manage their daily tasks. Because of my family's background in farming, this project is very special to me.
*   **My role:** My team and I built the technology that won us the first-place prize at our university.

🛡️ **SIH Dark-Web Deanonymization**
*   **What it is:** A major cybersecurity project built for the Smart India Hackathon (SIH). 
*   **Impact:** It focuses on finding hidden threats on the dark web and figuring out who is behind illegal activities to make the digital world safer.

🧠 **GyanAI-Tutor**
*   **What it is:** A smart, AI-powered tutoring application built using TypeScript[cite: 1].
